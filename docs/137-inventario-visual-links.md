## Objetivo

Substituir a leitura puramente tecnica do JSON por uma tabela operacional de links publicos no console web.

## Funcionalidades

- Lista links publicos com escopo, entidade, status e preview do hash.
- Mantem o token cru fora da interface.
- Permite revogar diretamente pela linha da tabela.
- Desativa a acao quando o link ja esta revogado.
- Atualiza o inventario apos revogacao pela linha.

## Valor Para A Operacao

A equipe administrativa consegue enxergar quais links continuam ativos e encerrar acessos especificos sem manipular URLs publicas completas.
