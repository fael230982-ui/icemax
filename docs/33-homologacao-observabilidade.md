# Homologacao E Observabilidade

## Objetivo

Facilitar validacao profissional do produto antes de liberar ambiente para teste com cliente, tecnico ou parceiro.

## Endpoints

- `GET /api-contract/routes`
- `GET /homologation/scenarios`
- `POST /homologation/scenarios/:key/run`
- `GET /observability/summary`
- `GET /demo-data/snapshot`

## Cenarios Iniciais

- OS corretiva completa.
- Contrato recorrente com visita preventiva.
- Atendimento com fila offline.
- Preparacao whitelabel.

## Uso

O console web possui a acao `Homologacao`, que executa contratos, cenarios, observabilidade e snapshot de dados mockados.
