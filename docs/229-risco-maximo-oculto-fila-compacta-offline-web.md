## Objetivo

Indicar se existem pendencias de alto risco fora dos seis cards visiveis da fila diaria compacta offline.

## Entrega

- Lista de itens ocultos calculada a partir do recorte compacto atual.
- Indicador `Risco oculto` com maior severidade fora dos cards visiveis.
- Exibicao apenas quando houver itens ocultos.
- Destaque visual critico para severidade igual ou superior a 85.

## Impacto Operacional

Ajuda o gestor a decidir se deve abrir a tabela completa antes de agir nos cards visiveis, evitando que uma pendencia critica fique fora do comando diario.

## Proximo Avanco Recomendado

Adicionar atalho para rolar ate a tabela completa quando houver risco oculto critico.
