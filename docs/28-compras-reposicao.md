# Compras E Reposicao

## Objetivo

Sugerir compras quando estoque estiver abaixo do minimo.

## Implementacao Atual

- `GET /purchase-requests/suggestions`
- `POST /purchase-requests`
- Calcula quantidade sugerida com base no estoque minimo.

## Proxima Evolucao

Adicionar fornecedores, cotacoes, aprovacao e entrada automatica no estoque.
