# Alerta De Itens Ocultos Na Fila Compacta

Copyright (c) 2026 RAFAEL DA SILVA BEZEERA
All rights reserved.

## Objetivo

Destacar visualmente quando a fila compacta possui pendencias ocultas alem dos seis cards visiveis.

## Entrega

- Badge de atencao para `Ocultas` quando o contador for maior que zero.
- Estado neutro quando nao houver itens ocultos.
- Padrao visual alinhado aos badges de severidade ja existentes.
- Indicacao mais clara para o gestor consultar a tabela completa.

## Impacto Operacional

O gestor percebe rapidamente quando a fila compacta nao representa todo o volume do recorte atual, reduzindo risco de deixar pendencias sem tratamento.

## Proximo Avanco Recomendado

Adicionar uma acao rapida para limpar filtros compactos e voltar ao estado padrao da fila.
