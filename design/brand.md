# Marca ICEMAX

## Arquivo Base

- Logo recebido: `icemax.PNG`

## Leitura Visual

- Marca com foco em frio, brilho tecnico e ar-condicionado.
- Cores dominantes: azul profundo, azul eletrico, ciano e fundo escuro.
- A interface deve usar essa identidade com cuidado: fundo claro para operacao diaria e acentos azuis para reforco de marca.

## Tokens Iniciais

- Azul primario: `#0B7CEB`
- Ciano destaque: `#28D8FF`
- Azul escuro: `#06243A`
- Texto principal: `#102033`
- Texto secundario: `#5D6B7A`
- Fundo: `#F4F8FB`
- Superficie: `#FFFFFF`
- Borda: `#DCE7F0`
- Sucesso: `#0E9F6E`
- Alerta: `#F59E0B`
- Urgencia: `#DC2626`

## Direcao De Interface

- Operacional, limpa e densa.
- Evitar visual excessivamente escuro em telas de uso diario.
- Usar azul/ciano em barras, botoes principais e indicadores.
- Dashboards devem priorizar leitura rapida.
